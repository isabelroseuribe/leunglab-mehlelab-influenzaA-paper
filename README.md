# leunglab-mehlelab-influenzaA-paper

Zhang, Z. and Uribe, I. et al. (2025). Global remodeling of ADP-ribosylation by PARP1 suppresses influenza A virus infection. Nature Communications. DOI: 10.1038/s41467-025-66136-6.

Example of scripts used to process each of the mass spectrometry-based proteomics datasets. These scripts were tailored to the number of biological conditions for ELTA-MS #1 (experimentally processed by Lyle), ELTA-MS #2 (experimentally processed by Mohsen), and ELTA-MS #3 (experimentally processed by me) for data analysis.

Scripts here are tailored for the ELTA-MS #3 dataset. The final output of these scripts was manually organized to produce Supplementary Table 3 which can be found here: https://www.nature.com/articles/s41467-025-66136-6#MOESM3. 

See the following workflows of numbered scripts to recreate the following figures/supplemental table associated with ELTA-MS #3:
-Supplementary table 3: script 01, script 02, script 03, script 04, script 06
-Heatmap in figure 5B: script 01, script 02, script 03, script 05
-Heatmap in figure 5f: script 01, script 02, script 03, script 04, script 06, script 07  
-Venn diagrams of of ADPr sites and proteins modified in each biological or technical replicate: script 01, script 02, script 03, script 04, script 06, script 09
